## 🚀 Project Overview
This project is an end-to-end Data Analytics solution designed to analyze historical sales data and predict future demand. It helps businesses improve inventory planning, sales forecasting, and decision-making using Power BI, SQL, and DAX.

---

## 🎯 Objective
To build a forecasting dashboard that:
- Analyzes historical sales trends
- Predicts future demand
- Identifies high/low demand products
- Improves inventory and supply chain planning

---

## 🛠 Tools & Technologies
- SQL (PostgreSQL)
- Power BI
- DAX
- Excel
- Data Modeling (Star Schema)

---

## 📊 Dataset Overview
The dataset includes:
- Orders, Products, Regions
- Sales & Units Sold
- Forecasted vs Actual Sales
- Inventory & Stock Risk
- Seasonal Trends

---

## 🧱 Data Model
Star Schema design:
- Fact Table: Fact_Sales
- Dimensions:
  - Dim_Date
  - Dim_Product
  - Dim_Region

Includes disconnected forecast table for analysis.

## 🔑 Key KPIs
- Total Sales: ₹6.17B  
- Total Units Sold: 478K  
- Forecast Accuracy: 93.48%  
- Forecast Error: 6.52%  
- Demand Growth: 0.07%

## 📊 Key Insights
- West region is the top-performing region
- Electronics dominates total revenue
- Overstocked inventory accounts for majority share
- Jackets and Microwaves are top demand products
- Seasonal demand peaks in Summer and Monsoon
